Projects & export

All artwork, music and generated speech travel with the project. Edits are kept in memory until you save. Preview is WebGL when supported, with a CPU fallback.

Browser recording runs in real time and requires keeping the tab visible. Output is MP4 if supported, otherwise WebM. The included headless renderer produces MP4 independently of browser recording.

Character & action reference

Characters: person, worker, scholar, knight, robot, traveler, deer, rabbit, badger, squirrel, blank-human, blank-skater, skater. The library adds 58 action presets, 22 effects, 90 props and 48 sets; see docs/LIBRARY.md. Actions: talk, think, observe, gesture, walk, run, march, dance, swing, aim, attack, fall, brace, sit, paper, strike, stomp, down, reach. Props: rifle, knife, spear, top, box, tablet, slime.

Actor JSON: kind, action, from/to [x,y,z], scale, rotation (radians), optional prop, armedAt (0–1), beats [{at:0–1,action,position,rotation,scale}]. Actors support keys [{at,position,rotation}], visibleFrom/visibleUntil and disarmedAt. Scene props support keys, open, visibleFrom/visibleUntil and owners [{at,actor:id}]. Shot and action times are normalized 0–1. Ownership transfers keep a single prop instance; inspect the saved shot list for examples. All animation is deterministic at a requested timestamp. Headless API: CartoonStudio.validate, timeline, locate, stage, update, SoftwareRenderer.

Ready-to-use cast · 60 characters

Five genres, original textured outfits and shared articulated motion. Choose a character card, then add it or apply it to the selected actor. All appearance fields remain editable in Actors JSON.

The helper uses the selected genre and avoids presets already in this scene. It never replaces existing characters. Explicit story identities should always be selected deliberately.

Scene editor

Traditional synthetic speech is generated locally. It does not clone anyone’s voice. Higher-quality recordings can be imported without changing the animation.

Fresh stills

Capture a movie moment, or change the copied scene JSON to compose a fresh pose and camera. Your original movie stays unchanged. No transition fade is applied.

Edit fresh scene: camera / target / actors / props / shots

To use the camera and target directly, set shots to an empty array. Actor rotation is in radians; normalized animation times are 0–1. Copy a scene first, then adjust its values.

Comic pages

Capture current scenes as independent panel snapshots. Compose a page, edit its captions and bubbles, and export an editable project or a multi-page PDF. All assets stay embedded. Changes are in memory until saved.

Bubble and caption guide

A panel can have caption text and a balloons array. Example: {"kind":"speech","text":"Hello!","x":0.05,"y":0.05,"w":0.65,"h":0.25,"tail":[0.7,0.5],"fontSize":22}. Coordinates are fractions of the panel. Kinds: speech, thought, caption. Optional text controls: allCaps, strokeColor, strokeWidth, color, fill. Oversized text causes an explicit export error instead of being silently cut off. Use panel sceneOverride to change its pose without changing the movie. Cover and credits pages can also have a text field.
