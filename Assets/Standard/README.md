# Actual offline CC0 assets

These five GLBs are the complete runtime asset subset described in [the asset inventory](../../docs/STANDARD_ASSETS.json). Original URLs and SHA-256 are in that inventory and `Source/standard-assets.json`; the build verifies those hashes and embeds the files. No runtime download is needed.

The genuine ActionForge rig/T-pose/idle are Quaternius CC0 media repackaged by CGstuff, not ActionForge application code. The two Quaternius GLBs are the official free Standard 43-clip library, not the full paid-inclusive advertised collection. See the preserved [ActionForge notice](../../docs/ACTIONFORGE-THIRD-PARTY-NOTICES.txt) and [Quaternius license](../../docs/UAL-License.txt).
