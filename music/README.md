# Emotion Music Library

Original emotion-based songs by Nicholas Alexander Benson (Jet Black), included by the creator’s explicit authorization for this public studio release. These recordings are licensed under GPL-3.0-only with this repository; retain attribution and the license when redistributing them. Third-party imported music is not covered by this permission.

The manifest records exact SHA-256 hashes of the MP3 library recordings. Container and codec were checked with FFprobe; all ten were fully decoded with FFmpeg. The supplied library bytes were retained without additional audio conversion. The build embeds all ten tracks in the offline application and generated Demo.jetcartoon.json. No private story, project, or storage identifiers are included.

The ten compositions are Tranquility, Suspense, Determination, Playfulness, Anger, Fear, Nostalgia, Excitement, Sorrow and Joy. The original four track IDs and file bytes remain unchanged when the six additional approved recordings are added. All ten included files match the creator-supplied approved source bytes; no further transcoding is performed.
