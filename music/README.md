# Emotion Music Library

Original emotion-based songs by Nicholas Alexander Benson (Jet Black), included by the creator’s explicit authorization for this public studio release. These recordings are licensed under GPL-3.0-only with this repository; retain attribution and the license when redistributing them. Third-party imported music is not covered by this permission.

The manifest records exact SHA-256 hashes of the MP3 library recordings. Container and codec were checked with FFprobe; all four were fully decoded with FFmpeg. The supplied library bytes were retained without additional audio conversion. The build embeds all four tracks in the offline application and generated Demo.jetcartoon.json. No private story, project, or storage identifiers are included.
